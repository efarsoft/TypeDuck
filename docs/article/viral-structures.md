# 公众号爆款文章结构方法论（六型适配）

> 核心洞察：完读率低不是内容差，是「结构没匹配读者动机」
> 原则：结构为内容服务，别为了套模板丢了真实细节和个人声音

## 六型速查

### 1. 问题解决型（完读率最高）
痛点钩子 → 结果背书 → 步骤拆解 → 避坑提醒 → 行动指引

### 2. 故事连载型（追更率最高）
钩子场景 → 冲突升级 → 解决过程 → 价值升华 → 下集预告

### 3. 认知颠覆型（转发率最高）
反常识结论 → 证据支撑 → 逻辑推导 → 行动建议 → 价值延伸

### 4. 清单干货型（收藏率最高）
明确收益 → 分点清单 → 实操细节 → 资源链接 → 透明说明

### 5. 情绪共鸣型（互动率最高）
场景代入 → 情绪共情 → 解决方案 → 价值认同 → 行动号召

### 6. 场景演示型（转化率最高）
场景设定 → 旧操作对比 → 新操作演示 → 效果对比 → 行动指引

## 避坑（别丢灵魂）

1. **保留真实细节**：翻车现场、报错信息、实际时间——这是区别于其他教程的核心
2. **别硬套结构**：内容有更自然的叙事逻辑时，不强行套模板
3. **算法偏好**：问题解决型和认知颠覆型最容易过冷启动；清单干货型拿长尾；故事连载型拉追更

## 组合技巧

- 故事 + 问题解决 = 开头故事钩子 + 中间步骤拆解 + 结尾行动指引
- 认知颠覆 + 清单 = 开头反常识 + 中间功能清单 + 结尾操作建议
- 问题解决 + 情绪共鸣 = 开头痛点 + 中间解决 + 结尾共情号召
