这是「人人可入门的 AI 开发课程系统」的第 0 天。

很多人一听“AI 开发”就被开发环境劝退——装 Node、配 Key、过网络，第一步就卡死。所以 Day 0 不写代码，先把这道坎平了：选对工具、装好就能跑。

今天要装的三个工具，各有各的定位：

- **DeepSeek（网页版）** ——连客户端都不用装，浏览器打开就能用，开发前梳理需求最顺手

别担心耗时，全程实操也就 **5 分钟左右**，喝口水就装完了，装完立刻能用。除了告诉你怎么装，我顺手把几个容易卡住的弹窗和山寨站点标出来，省得你愣三秒。

## 0. 为什么讲这三个

Claude Code、Codex 那些终端 Agent 确实强，但得先装 Node、配 Key、过网络关，新手容易卡在第一步。

如果你只想**最快用上 AI 干活**——写代码、查资料、读项目、写文档、做 PPT、批量处理文件——那下面这三个是门槛最低的入口：一个网页版、一个桌面 Agent、一个桌面办公台。打开 / 下载、登录，完事。

一句话区分（按开发流程排）：

| 工具 | 出品方 | 定位 | 一句话描述 |
| --- | --- | --- | --- |
| **DeepSeek** | 深度求索 | 网页版 AI 问答 | 连客户端都不用装，浏览器打开就能问，开发前用来**梳理需求、查技术选型**最顺手 |
| **ZCode** | 智谱 Z.ai | 智能体开发环境（ADE） | **写代码 / 跑长任务**，对国内网络友好，后面几天的主力 |

## 1. DeepSeek（网页版）：开发前先理清需求

DeepSeek 是深度求索出品的 AI，网页版是它**门槛最低的形态**——没有安装包、没有命令行、没有 Key，**浏览器开个标签页就是“装”好了**。

我习惯在正式动手写代码前，先开它的网页版把需求嚼碎、把技术选型查清楚：它最省事，连装都不用装，问完关掉就行。2026 年现在的网页端默认 1M 上下文，深度思考（R1/V3）和联网搜索都能开，写代码、查资料、写文案、随手问都够用。

![图片](公众号原文配图)

### 入口

直接打开：**https://chat.deepseek.com**（或访问 https://www.deepseek.com 点首页“开始对话”也行）。

- 建议用 **Chrome / Edge**（Chromium 内核），加载和输入延迟都最稳；Safari 在代码块排版上偶尔错位，手机浏览器别拿来写长文。

### 登录

- 国内手机号 **收验证码** 登录即可，免 Key。
- 不登录也能直接试用，但登录后能保留历史对话。

### 验证

打开页面，对话框里发一句“用 Python 写个快速排序”，它能秒回带注释的代码，说明跑通了。右下角记得按需要开 **深度思考** 或 **联网搜索**。

### 避坑

网页版没有安装步骤，真正的坑只有一个：**别进错网址**。认准官方域名 `chat.deepseek.com` / `deepseek.com`——`deepseek` 是一个单词不带连字符，后缀只能是 `.com`。带连字符的（`deep-seek.com`）、或 `.net` / `.ai` / `.cn` 的，全是山寨碰瓷站，别下载它推的第三方 App。

## 2. ZCode：智能体开发环境（ADE）

ZCode 是智谱 Z.ai 推出的桌面端 AI 编程工具，定位为 **Agentic Development Environment（ADE，智能体开发环境）**。它不是那种你问一句它答一句的聊天框，而是**以“任务”为单位组织工作流**——你给它一个开发目标，它自己拆解步骤、调工具、写代码、跑测试，端到端干完。

目前稳定版本 v3.5.2，提供 macOS 与 Windows 双端安装包，Linux 还在内测。新用户送 **5 天免费体验额度**（GLM-5.2 每日 300 万 Token + GLM-5-turbo 每日 200 万 Token）。如果你已经有 Claude Code 的历史对话，ZCode 还支持一键迁移导入。

![图片](公众号原文配图)

**核心亮点**：

- **GLM-5.2 大模型加持**：1M 无损上下文窗口，长任务不“断片”，缓存命中率号称 98% 以上
- **自研 ZCode Agent 内核**：围绕 Agent 组织任务、权限、上下文、工具调用
- **分组式任务工作区**：支持拖拽折叠、跨区迁移、批量管理，多 Agent 并发任务一目了然
- **智能项目知识库（Zread）**：目录浏览、进度监测、一键重生成、随时终止构建
- **可视化 Git 分支图谱**：直观呈现分支拓扑关系，支持快捷切分支、AI 自动生成提交注释
- **BYOK 模式**：自带 API Key 也能用，不强制绑订阅
- **多端协同**：桌面端 + 手机端 Remote + 飞书/微信 Bot 可共同推进同一任务

**下载与安装**

官网：**https://zcode.z.ai/cn**。安装包托管在官方 CDN `cdn-zcode.z.ai`。

- **macOS**：下载 `.dmg`，拖进“应用程序”文件夹。**M 系列芯片务必选 arm64 版**，下成 x64 会走 Rosetta 转译，长任务明显掉速。
- **Windows**：下载 `.exe`，双击按向导安装。
- **Linux**：加入飞书内测群获取安装包，部分发行版需装 `fuse` 依赖。

**首次启动**

打开 ZCode，有两种方式接入：

1. **连接 Z.ai / BigModel 账号**：新用户有免费体验额度，登录即用
2. **填 API Key / 自定义供应商**：如果你已有其他模型的 API Key，在设置里添加供应商即可

进入主界面后，选一个本地项目目录作为工作区。在对话框输入“列出当前目录的文件结构”，Agent 正常响应就说明装好了。

## 3. WorkBuddy：全场景 AI 办公工作台

WorkBuddy 是腾讯 2026 年 3 月 9 日正式上线的**全场景职场 AI 原生智能体桌面工作台**，被称为“腾讯版 OpenClaw”。跟网页版 AI 聊天最大的区别是：**它能直接操作你电脑里的文件**——读写 Excel、生成 Word、做 PPT、执行命令，甚至定时自动跑任务。

上线后热度飙升，发布当月 PC 端月访问量 885 万，到 2026 年 6 月突破 **2097 万**，三个月增长 2.4 倍，在 PC 端 AI 原生办公智能体市场排名第一。

![图片](公众号原文配图)

**核心能力**：

- **智能任务自动化执行**：听得懂口语化指令，自主拆解步骤、全自动执行，无需人工值守
- **本地文件全流程操作**：批量重命名、Excel 透视表与图表、PDF 解析、Word/PPT 生成
- **多模态办公内容创作**：文案撰写、PPT 全自动制作、海报生成、数据图表绘制
- **跨平台远程控制**：通过微信/企业微信发消息，“遥控”电脑干活
- **多 Agent 并行**：复杂任务拆解后多个 AI 同时开工
- **五大模型自由切换**：混元、DeepSeek、GLM、Kimi、MiniMax 任选
- **超 20 种 Skills 技能包**：零代码扩展能力，完全兼容 OpenClaw 体系

**下载与安装**

官网：**https://www.workbuddy.cn**（也可从 **https://www.codebuddy.cn/work** 进入）。

- **Windows**：下载 `.exe`，双击安装
- **macOS**：下载 `.dmg`，拖进“应用程序”
- **Linux**：下载 `.deb`（Ubuntu/Debian）或 `.rpm`（Fedora/RHEL）

打开后**微信或手机号扫码登录，30 秒搞定**。新用户一般送免费积分，轻度使用够用。

**验证**

登录后在对话框输入“帮我写一份本周工作周报并存成 Word”，几秒拿到文件，说明跑通了。

## 4. 三个怎么一起用

按开发流程排，正好串成一条线：

- **开发前梳理需求 / 随手查资料 / 在别人电脑上临时用** → 开 DeepSeek 网页版
- **写代码 / 跑 Agent 长任务（主力开发）** → 上 ZCode
- **写文档 / 做 PPT / 批量杂活 / 也能写代码** → 上 WorkBuddy

> **说句大实话**：如果是**不复杂的工具 / 小脚本开发**，ZCode 和 WorkBuddy 任选一个就够——它俩在轻度开发上能力重叠，不用纠结“该用哪个”，挑顺手的先跑起来最重要。

典型一天：动手前先用 DeepSeek 网页版把需求和技术选型嚼碎；上午用 WorkBuddy 把周报、PPT 出了；下午用 ZCode 在真实项目目录里让 Agent 改代码、跑测试。

> **那为什么不直接用 ZCode 或 WorkBuddy 的对话框来聊需求呢？**
>
> 问得好。答案就一个字：**抠**。
>
> DeepSeek 网页版**完全免费**，1M 上下文，随便问，问一百遍也不心疼。ZCode 虽然新用户有免费额度，但那是用来跑 Agent 写代码的——拿来闲聊式地聊需求，总感觉有点“大炮打蚊子”。WorkBuddy 的免费积分也是同理，留着做 PPT 不香吗？
>
> 说白了就是一句话：**DeepSeek 聊需求不要钱，ZCode 和 WorkBuddy 的额度要省着给正活用。** 虽然 Token 没几个钱，但该省省该花花，骑着单车去酒吧，你懂的。
>
> 所以我的工作流很固定：DeepSeek 当“前期军师”，需求聊透了、技术方案定下来了，再去 ZCode 里开干。顺手，且不心疼。

## 6. 写在最后

三个工具的共同点：**上手门槛低，基本不用配 Key**。区别只在“装到哪”和“侧重啥”——DeepSeek 装进浏览器标签页、专管梳理需求；ZCode 装进电脑、主力写代码；WorkBuddy 装进电脑、包圆办公 + 轻度开发。

对不想在环境上耗时间的人，这是最快上手 AI 的方式。装的时候遇到奇葩报错，评论区贴出来，咱一起排雷。

### 附：避坑小贴士

| 问题 | 解决方案 |
| --- | --- |
| **DeepSeek 进错网址** | 只认 `chat.deepseek.com` / `deepseek.com`，带连字符或 `.net`/`.ai`/`.cn` 的都是山寨 |
