FAQ

常见问题

关于排版鸭，被问得最多的五个问题。

排版鸭是什么？和 mdnice、Doocs md 有什么区别？

排版鸭（TypeDuck）是一款免费开源的微信公众号 Markdown 排版工具，MIT 协议。区别在于：不需要注册登录、数据 100% 存本地、AI 功能自带 Key 自助使用（BYOK）、提供桌面客户端，且从热点选题到草稿直发覆盖写作全流程。

复制到公众号后，样式会丢失吗？

不会。排版鸭把所有样式转成内联样式（inline style）并做加固，避开微信编辑器会剥离的 class 与 style 标签；标题、引用、代码高亮、表格粘贴后所见即所得。导出 Word 时自动切换为兼容样式。

需要注册或登录吗？我的文章存在哪里？

不需要注册登录。文档存在你浏览器的本地存储（IndexedDB）里，桌面版存在本机——全程不经过任何服务器，离线也能用。

以后会收费吗？

不会。排版鸭采用 MIT 协议开源，所有功能永久免费——无会员、无广告、无阉割，功能只增不减，这一点写进了开源协议。 AI 采用 BYOK 模式：在 DeepSeek、豆包、通义千问、GLM、Kimi 等厂商自助申请免费 API Key 填入即可，额度和内容都在你自己手里。

支持哪些平台？

网页版打开即用（本页面「开始使用」）；桌面版支持 Windows 与 macOS，安装包发布在 GitHub Releases，还额外支持热点抓取、公众号草稿箱直发等桌面专属能力。
